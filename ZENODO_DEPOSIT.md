# How to deposit this paper on your Zenodo account

This package is formatted for a Zenodo “Publication → Working paper” upload. The authors of this environment cannot log into your Zenodo account. The deposit takes about five minutes.

## Files to upload

- `Frohman_2026_Displacement_Without_Redundancy.pdf` (version of record)
- `Frohman_2026_Displacement_Without_Redundancy.md` (source)
- `CITATION.cff` (optional but useful)

## Steps

1. Go to https://zenodo.org and sign in (ORCID login is the usual path).
2. Click **New upload** / **Upload**.
3. Drop in the PDF (and, if you wish, the Markdown source).
4. Resource type: **Publication** → **Working paper**.
5. Title: `Displacement Without Redundancy: Ricardo’s Machinery Chapter, the Acemoglu–Restrepo Task Model, and Four Years of Generative AI`
6. Additional title / subtitle if the form allows: `United States Evidence and a Western Comparison, 2016–2026`
7. Creators: `Frohman, Benjamin` (add ORCID if you have one).
8. Publication date: `2026-09-08`.
9. Version: `1.1`
10. Description: paste the abstract from the PDF.
11. License: **Creative Commons Attribution 4.0 International** (CC-BY-4.0).
12. Keywords: `task model`, `Ricardo`, `automation`, `generative AI`, `labor share`, `Luddite fallacy`, `displacement`, `reinstatement`, `Western labour markets`, `canary residual`.
13. Related identifiers (optional): BLS series IDs in the data appendix; GitHub repo if you publish one.
14. Visibility: **Public**.
15. Click **Publish**. Zenodo will mint a DOI.

If version 1.0 was already published, use **New version** on that record rather than creating a second record. Zenodo will mint a versioned DOI (`10.5281/zenodo.xxxxxxx`) and keep the concept DOI stable.

## GitHub → Zenodo (optional)

If a public GitHub repository exists for this paper, install the Zenodo GitHub app, then create a release tagged `v1.1.0`. Zenodo will mint a versioned DOI from the release.

## What this is not

This is a working paper, not a peer-reviewed journal article. Zenodo will host it with a DOI. It will not become an *American Economic Review* article.
