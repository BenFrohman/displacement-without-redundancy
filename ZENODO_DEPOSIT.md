# How to deposit this paper on your Zenodo account

This package is formatted for a Zenodo “Publication → Working paper” upload. The deposit takes about five minutes.

## Files to upload

- `Frohman_2026_Displacement_Without_Redundancy.pdf` (version of record)
- `Frohman_2026_Displacement_Without_Redundancy.md` (source)
- `CITATION.cff` (optional)

## Steps

1. Go to https://zenodo.org and sign in (ORCID login is the usual path).
2. Click **New upload** / **Upload**.
3. Drop in the PDF (and, if you wish, the Markdown source).
4. Resource type: **Publication** → **Working paper**.
5. Title: copy from the PDF title page.
6. Creators: `Frohman, Benjamin` (add ORCID if you have one).
7. Publication date: `2026-09-08`.
8. Description: paste the abstract.
9. License: **Creative Commons Attribution 4.0 International** (CC-BY-4.0).
10. Keywords: `task model`, `Ricardo`, `automation`, `generative AI`, `labor share`, `Luddite fallacy`, `employment projections`, `displacement`, `reinstatement`.
11. Related identifiers (optional): GitHub repo https://github.com/BenFrohman/displacement-without-redundancy
12. Visibility: **Public**.
13. Click **Publish**. Zenodo will mint a DOI.

## GitHub → Zenodo (optional)

Connect this repository at https://zenodo.org/account/settings/github, then create a GitHub Release. Zenodo will mint a versioned DOI from the release tag.

## What this is not

This is a working paper, not a peer-reviewed journal article. Zenodo will host it with a DOI.
